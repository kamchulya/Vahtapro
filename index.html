01

Табели и KPI

Начальник участка собирает данные по бригаде, система автоматически сверяет с графиком и отпусками. HR проверяет только расхождения. KPI по умолчанию 1.0, начальник фиксирует только инциденты.

02

Приём, перевод, отпуск

Служебка с телефона → апрув директора → данные из eGov по ИИН. Договор подписывается удалённо. Enbek.kz обновляется без участия HR.

03

AI Онбординг

Сотрудник задаёт вопросы чат-боту: "Сколько платят за ночные?", "Где столовая?", "Кто мой бригадир?". Бот отвечает на основе ваших внутренних документов.
